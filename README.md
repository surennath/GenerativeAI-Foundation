# GenerativeAI-Foundation
In this lab, you will explore how different Generative AI tools respond to the same or similar prompts. You will test a text tool, an image tool, and a chatbot tool, compare their outputs, and document what you learned about what AI can and cannot do.

What You Will Build

By the end of this lab, you will create a small project folder that includes:

A list of the 3 AI tools you tested
The prompts you used Screenshots or saved outputs from each tool
A comparison of the results A written reflection: “What AI can and cannot do”
A GitHub repository containing your completed lab work 


Tools You Can Use

You may choose any 3 Generative AI tools. For this lab, use one tool from each category.

1. Text Generation Tool

Examples:
ChatGPT
Claude
Gemini
Microsoft Copilot

Use this tool to generate written content such as explanations, emails, summaries, or blog drafts.

2. Image Generation Tool

Examples:
DALL·E
Midjourney
Adobe Firefly
Canva AI image generator
Leonardo AI

Use this tool to generate an image from a text prompt.

3. Chatbot / Assistant Tool

Examples:
ChatGPT
Claude
Gemini
Perplexity
Microsoft Copilot

Use this tool to have a conversation, ask follow-up questions, or request reasoning and explanation.

You may use ChatGPT for one category, but try to use at least two different platforms if possible so you can compare differences.
